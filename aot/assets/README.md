# Game files

Put the extracted contents of your own copy of the game disc here
(`default.xex`, `AO2Game/`, ...). They are not part of this repository.

This branch is built for Title Update 2: also put `default.xexp` (the only
file in the TU2 package `TU_12K222C_0000004000000.00000000000G1`) next to
`default.xex`. Codegen and the game both apply it on load. Downloadable
content goes, extracted, to the user data folder
(`Documents/armyoftworecomp_tu2/0000000000000000/4541084C/00000002/<package>/`,
see ../docs/tu2.md).
